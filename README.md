# TinyMLOps for Real-Time Keyword Spotting (RT-KWS)

This repository contains the official thesis documentation, pipeline architecture diagrams, and deployment logic for a production-grade **TinyMLOps Framework**. The project demonstrates how to fully automate the training, optimization, and bare-metal deployment of a 1-Dimensional Convolutional Neural Network (1D-CNN) for Real-Time Keyword Spotting on deeply embedded, resource-constrained microcontrollers.
